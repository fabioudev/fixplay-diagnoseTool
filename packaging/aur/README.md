# AUR Package: fixplay-diagnosetool-bin

This directory contains the AUR PKGBUILD for `fixplay-diagnosetool-bin`, a binary-package variant that downloads precompiled AppImage releases from GitHub.

## Structure

```
packaging/aur/fixplay-diagnosetool-bin/
├── PKGBUILD       # Main build script
└── .SRCINFO       # AUR metadata (auto-generated by mksrcinfo)
```

## Building Locally

To test the package before submission to AUR:

```bash
cd packaging/aur/fixplay-diagnosetool-bin
makepkg -si
```

## Debugging

If the build fails, you can inspect what's being downloaded:

```bash
cd packaging/aur/fixplay-diagnosetool-bin
makepkg --nobuild --noextract  # Just download sources
ls -la src/
```

## Updating

When a new release is published on GitHub:

1. Update `pkgver` in `PKGBUILD`
2. Update `pkgrel` back to `1` (or increment if same version)
3. Run `mksrcinfo` to regenerate `.SRCINFO`:
   ```bash
   mksrcinfo
   ```
4. Commit and push to AUR

## Publishing to AUR

Once ready, create a Git SSH key pair for the AUR account and clone the AUR repo:

```bash
git clone ssh://aur@aur.archlinux.org/fixplay-diagnosetool-bin.git aur-repo
cd aur-repo
# Copy PKGBUILD and .SRCINFO from this directory
cp ../packaging/aur/fixplay-diagnosetool-bin/{PKGBUILD,.SRCINFO} .
git add .
git commit -m "Update to version <version>"
git push
```
