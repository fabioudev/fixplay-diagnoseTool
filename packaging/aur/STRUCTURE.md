# AUR Package Structure

Complete directory structure for `fixplay-diagnosetool-bin` on AUR.

```
packaging/aur/
├── .gitignore                          # Git ignore for build artifacts
├── README.md                           # AUR package overview
├── PUBLISHING.md                       # Step-by-step publishing guide
├── update-aur.sh                       # Automated version update script
└── fixplay-diagnosetool-bin/
    ├── PKGBUILD                        # Main build script
    └── .SRCINFO                        # AUR metadata (auto-generated)
```

## File Descriptions

### `.gitignore`
Prevents accidental commits of build artifacts (src/, pkg/, *.tar.zst, etc.)

### `README.md`
Quick reference for building and testing the AUR package locally.

### `PUBLISHING.md`
**START HERE** - Complete guide from creating an AUR account to publishing and maintaining the package.

### `update-aur.sh`
Automated script that:
1. Fetches latest GitHub release version
2. Updates PKGBUILD with new version
3. Regenerates .SRCINFO
4. Provides next steps for git push

Usage:
```bash
./packaging/aur/update-aur.sh
```

### `fixplay-diagnosetool-bin/PKGBUILD`
The AUR build script that:
- Downloads the AppImage from GitHub Releases
- Installs it to `/opt/fixplay-diagnosetool-bin`
- Creates a wrapper script in `/usr/bin/fixplay-diagnosetool`
- Installs desktop entry and icon

### `fixplay-diagnosetool-bin/.SRCINFO`
AUR metadata file. Auto-generated by `mksrcinfo`. Do not edit manually.

## Quick Start for AUR Submission

1. **Read**: `PUBLISHING.md`
2. **Test locally**:
   ```bash
   cd packaging/aur/fixplay-diagnosetool-bin
   makepkg -si
   ```
3. **Push to AUR**: Follow steps in `PUBLISHING.md`

## Version Updates

For each new GitHub release:

```bash
./packaging/aur/update-aur.sh
cd packaging/aur/fixplay-diagnosetool-bin
git add PKGBUILD .SRCINFO
git commit -m "Update to <version>"
git push
```

## Integration with GitHub Actions (Optional)

To automatically update AUR on each release, you could add a GitHub Actions job that:
1. Triggers on new tags
2. Runs `update-aur.sh`
3. Commits and pushes to AUR

See `.github/workflows/release.yml` for existing GitHub Actions setup.
